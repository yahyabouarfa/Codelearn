💻 EXEMPLES FRONTEND

React/Next.js:
───────────────
fetch('http://localhost:8084/api/cours/liste')
  .then(r => r.json())
  .then(data => console.log(data));

Angular:
────────
this.http.get('http://localhost:8084/api/cours/liste')
  .subscribe(data => console.log(data));

Vue/Nuxt:
─────────
axios.get('http://localhost:8084/api/cours/liste')
  .then(r => console.log(r.data));

Upload Fichier:
───────────────
const formData = new FormData();
formData.append('file', file);
formData.append('typeSupport', 'PDF');

fetch('http://localhost:8084/api/cours/1/supports/upload', {
  method: 'POST',
  body: formData
});
